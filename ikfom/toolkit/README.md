# IKFoM toolkit

Adapted from [IKFoM](https://github.com/hku-mars/IKFoM) (Iterated Kalman Filters on Manifolds,
Dongjiao He, The University of Hong Kong), which builds on MTK (Christoph Hertzberg,
Universität Bremen). `mtk/macros_utils.h` is adapted from
[map-macro](https://github.com/swansontec/map-macro) (CC0 1.0).
